# Lalana fampandrosoana — Fanorona Online

## Tanjona
Hanangana sehatra Fanorona malagasy natao ho an'ny finday, misy lalao marina, AI, lalao amin'ny mpilalao hafa, ary fifaninanana azo tantanana.

## Dingana sy fepetra hahavitana

### Dingana 1 — Fototra sy interface
- [x] Mamorona pejy fandraisana amin'ny teny Malagasy.
- [x] Mamorona endrika responsive ho an'ny finday.
- [x] Mampiseho solaitrabe 9 × 5.
- [x] Mampifandimby mpilalao roa amin'ny navigateur iray.
- [ ] Hamarino amin'ny navigateur Android ny layout sy ny rohy.

### Dingana 2 — Fanorona Riatra game engine
- [ ] Farito sy tehirizo ny topology marina amin'ny solaitrabe (toerana sy tsipika azo aleha).
- [x] Ampiharo ny fanombohan'ny lalao sy ny isan'ny vato.
- [x] Ampiharo ny hetsika ara-dalàna sy ny fanamarinana an-tery ny fakana vato.
- [x] Ampiharo ny fakana amin'ny fanatonana (approach) sy ny fialana (withdrawal).
- [x] Ampiharo ny fakana maromaro amin'ny anjaran'ny mpilalao iray.
- [x] Ampiharo ny fepetra tsy ahafahana miverina amin'ny toerana efa naleha mandritra ny fakana maromaro.
- [x] Manorata fitsapana fototra ho an'ny toe-javatra ara-dalàna sy tsy ara-dalàna.

**Sata:** vita ny dikan-teny voalohany; mbola mila fitsapana fanampiny sy fanamarinana ny topology amin'ny mpilalao mahay. Ny fitsapana mandeha amin'ny GitHub Actions dia manamarina tranga fototra, fa tsy mbola porofo fa feno avokoa ny fitsipika.

### Dingana 3 — Vela be

**Sata:** tafiditra ao amin'ny UI ny dingana voalohany sy faharoa. Rehefa vita ny Riatra dia solaitrabe vaovao no ampiasaina, samy manomboka amin'ny vato feno ny roa tonta. Ny mpandresy no manolotra vato, ny mpilalao Vela maka azy; rehefa dimy sisa ny mpandresy dia mitohy eo amin'io solaitrabe io ny dingana faharoa.
- [ ] Hamafiso miaraka amin'ny mpilalao mahay ny antsipirian'ny fitsipika sy ny fiafaran'ny dingana tsirairay.
- [x] Ampiharo ny dingana voalohany: manolotra vato tsirairay tsy maka, ary tsy maintsy maka ny Vela.
- [x] Ampiharo ny dingana faharoa rehefa tonga amin'ny vato dimy ny mpanolotra.
- [x] Ampiharo ny famaritana hoe afaka Vela na tsy afaka Vela.
- [x] Mamorona fototra mitantana ny dingana Vela sy ny scoring (5–3 na 8–0).
- [x] Manorata logic manamarina ny fanolorana vato sy ny fakana ilay vato natolotra amin'ny solaitrabe.
- [x] Ampifandraiso amin'ny UI ny dingana voalohany, ka ny hetsika tena izy no mampandroso ny session fa tsy bokotra fanisana.
- [x] Ampiharo ny solaitrabe vaovao misy vato feno ho an'ny roa tonta araka ny fanazavan'ny mpikarakara.
- [x] Ampifandraiso amin'ny solaitrabe ny dingana faharoa sy ny famaritana hoe afaka Vela na tsy afaka Vela.
- [ ] Hamarino amin'ny mpilalao Fanorona mahay fa mifanaraka amin'ny fitsipika eo an-toerana ny antsipirian'ny hetsika Vela.
- [ ] Tehirizo amin'ny tantaran'ny match ny vokatry ny Riatra sy ny Vela.

### Dingana 4 — Kaonty sy lalao an-tserasera
- [ ] Safidio sy amboary ny backend (ohatra Supabase).
- [ ] Ampidiro ny kaonty sy ny session.
- [ ] Ataovy ao amin'ny server ny fanamarinana hetsika rehetra.
- [ ] Ampidiro ny lalao mifanatrika sy ny fifandraisana indray rehefa tapaka ny internet.
- [ ] Tehirizo ny tantaran'ny lalao sy ny valiny.

### Dingana 5 — Fifaninanana
- [ ] Fisoratana anarana sy fanidiana fisoratana anarana.
- [ ] Fotoana fanomanana aorian'ny fisoratana anarana.
- [ ] Safidy format mifanaraka amin'ny isan'ny mpilalao.

- [ ] Fitantanana match, vokatra, fifandirana ary audit log.
- [ ] Fitsapana fifaninanana maimaim-poana alohan'ny hampidirana vola.

### Dingana 6 — Fandoavam-bola sy loka
- [ ] Hamarino ny fepetra ara-dalàna eto Madagasikara.
- [ ] Hamarino ny fomba fandoavam-bola, ny sarany, ny fanamarinana ny fandoavana ary ny famerenam-bola.
- [ ] Farito mialoha ny vola miditra, ny fandaniana, ny loka ary ny tahiry.
- [ ] Aza manokatra fifaninanana misy saram-pidirana raha tsy vita ireo fanamarinana ireo.

## Fanapahan-kevitra ara-teknika
- Tsy mila VPS amin'ny prototype static voalohany.
- Ny AI Fanorona dia tokony hampiasa algorithm sy fanombanana manokana; tsy voatery handoa API AI ivelany.
- Ny navigateur dia tsy tokony ho loharano farany amin'ny valin'ny lalao: ny server no manamarina ny hetsika sy ny vokatra.
- Tsy tehirizina ao amin'ny frontend ny secret keys.
